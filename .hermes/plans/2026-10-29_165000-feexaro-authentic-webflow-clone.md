# План: 100% Автентичне клонування шаблону Feexaro Webflow для сайту ремонту побутової техніки в Харкові (`rempobut/`)

**Дата:** 2026-10-29  
**Ціль:** Замінити спрощений макет `rempobut/` на автентичний, піксель-перфектний клон [Feexaro Webflow](https://feexaro.webflow.io/) за аналогією з успішним клоном Fixora (`fixora/`).  
**Проблема поточного стану:** У поточному `rempobut/` використовувався спрощений React/Tailwind шаблон з ненадійними посиланнями на Unsplash, через що в секції «Про компанію» («Дбаємо про вашу техніку») було порожнє місце замість фото, а візуальний вигляд поступався оригіналу.  
**Рішення:** Повний витяг оригінального Webflow DOM, оригінального CSS `feexaro.webflow.shared.540f5f62e.css`, усіх 109 оригінальних Webflow CDN-зображень, плашок, іконок та текстур, та їхня 100% харківська локалізація.

## 3. Фази реалізації

1. **Етап 1: Завантаження всіх Webflow ресурсів:**
   Скрипт Python скачує `feexaro.webflow.shared.540f5f62e.css`, скрипти `webflow.js` та всі зображення в локальні папки `rempobut/assets/`.
2. **Етап 2: Збірка піксель-перфектного `rempobut/index.html`:**
   Формування повної семантичної структури Webflow із збереженням усіх оригінальних класів (`w-layout-grid`, `hero-slider`, `about-image-wrapper`, `shape-badge`, `btn-pill` тощо).
3. **Етап 3: Верифікація за Залізним Законом:**
   - Тестування в `browser_exec` на десктопі (1440px) та мобільному (375px).
   - Аналіз скріншотів через `vision_analyze` для підтвердження наявності всіх фото та бездоганного вигляду.
4. **Етап 4: Деплой:**
   - `git add`, `git commit`, `git push origin main`.
   - Перевірка живого лінку `https://arch1cat.github.io/rempobut/`.
