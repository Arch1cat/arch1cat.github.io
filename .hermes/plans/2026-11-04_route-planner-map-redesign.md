# План: Інтерактивний навігаційний модуль маршрутів та капітальне поліпшення карти й дизайну ТехноVovk

**Дата:** 2026-11-04  
**Ціль:** 
1. **Повне видалення технічного сміття:** Прибрати «координати 49.9895° N, 36.2432° E» та будь-які штучні написи.
2. **Інтерактивна карта з побудовою маршруту прямо всередині сайту:**
   - Інтегрувати розумний навігатор маршрутів (Route Planner): вибір району відправлення (Салтівка, Олексіївка, Центр, Холодна Гора, Нові Будинки) або введення власної адреси / геолокація.
   - Миттєве оновлення карти Google Maps із прокладеним маршрутом (`saddr` -> `daddr`), розрахунком часу в дорозі на авто (хв) та громадським транспортом.
   - Перемикач режимів пересування: `[ 🚗 На авто ]`, `[ 🚇 Громадський транспорт / Метро ]`, `[ 🚶 Пішки ]`.
3. **Преміальний редизайн секції карти та всієї сторінки:**
   - Оформлення карти у стилі Dark Cyber-Industrial (темна рамка з неоновим бурштиновим бевелом, інтерактивні чипи швидкого маршруту).
   - Візуальні акценти на безкоштовному паркінгу прямо перед входом для вивантаження техніки.
   - Поліпшення загальної візуальної естетики сайту (шрифти, відступи, контрастність, кнопки, модальні вікна).

## 1. Архітектура інтерактивного модуля побудови маршрутів (Route Planner)

### 1.1. Інтерфейс інтерактивного навігатора
- **Поле введення відправної точки:** `Звідки їдете? (наприклад: Салтівка, вул. Героїв Праці або станція метро)`.
- **Швидкі чіпи районів Харкова:**
  - `[ Салтівка (~14 хв на авто) ]`
  - `[ Олексіївка (~18 хв на авто) ]`
  - `[ Центр (~6 хв на авто) ]`
  - `[ Холодна Гора (~12 хв на авто) ]`
  - `[ Нові Будинки (~10 хв на авто) ]`
- **Перемикач транспорту:**
  - `[ 🚗 Автомобіль ]` — показує прямий під'їзд до фасаду та паркомісця.
  - `[ 🚇 Метро / Трамвай ]` — показує пішохідний маршрут від м. «Захисників України» (650 м) або зупинки трамваїв №6/№8.
  - `[ 🚶 Пішки ]` — прямий пішохідний трек.
- **Динамічний iFrame карти:**
  - При виборі району або кліку на «Показати маршрут» iFrame автоматично перемикається на живий маршрут:
    `https://maps.google.com/maps?saddr={START_POINT}&daddr=проспект+Героїв+Харкова+35+Харків&output=embed`
  - Клієнт прямо всередині сторінки бачить лінію маршруту, повороти, завантаженість проспекту та фінішну точку майстерні!

### 1.2. Очищення від непотрібних елементів
- Повністю прибрати географічні координати.
- Замінити на живий статус: `● Майстерня працює сьогодні до 17:00 (прийом техніки) · Безкоштовний паркінг перед дверима`.

## 2. Глобальні покращення дизайну сайту
- **Header:** Додати інтерактивну кнопку швидкого виклику майстра з підсвічуванням при скролі.
- **Hero-блок:** Збільшити контрастність та насиченість зображення інженера, зробити плаваючі бейджі більш технологічними.
- **Секція діагностики:** Зробити клікабельні симптоми виразнішими з плавною анімацією вибору.
- **Калькулятор:** Посилити підсумковий чек, додавши динамічний індикатор знижки на діагностику (100% знижка = 0 грн).
- **Секція карти:** Створити цілісний командний пункт навігації з повноцінною картою та інтерактивними контролами.

## 3. План верифікації
1. Перевірити генерацію та роботу динамічної карти з маршрутами через браузер.
2. Протестувати роботу кліків по районах (Салтівка, Олексіївка, Центр тощо).
3. Зробити скріншоти та перевірити відсутність координат, коректність верстки та адаптивність через `vision_analyze`.
4. Закомітити та запушити на GitHub Pages.
