# AI Matrix — Unified Table Redesign Plan

## Проблема пользователя
Сейчас 4 разных таблицы (Overview, All Models, Exact IDs, Budget) — неудобно переключаться. Пользователь хочет ОДНУ удобную таблицу, где видно ВСЕ доступные AI (бесплатные + preview + paid) с полной информацией, и можно фильтровать/переключать прямо в ней.

## Цель
Одна главная таблица со всеми exact routes. Все фильтры (provider, kind, status, task, ctx, reasoning, search) работают прямо в ней. Дополнительные вкладки — только как вспомогательные (Budget, Verified). Никаких "4 таблиц" — одна главная.

## Архитектура
- **Главная вкладка "All Models"** становится основной и единственной таблицей со всеми данными.
- **Overview** сворачивается в компактные карточки провайдеров сверху (не отдельная таблица).
- **Exact IDs** удаляется как отдельная вкладка — ID уже в главной таблице.
- **Budget & Verified** остаются отдельной вкладкой (маленькая, не мешает).
- Вкладка переключения: "All Models" | "Budget & Verified".

## Колонки главной таблицы (одна строка = один exact route)
1. # (rank)
2. AI / семейство (название + сила)
3. Задачи (tags)
4. Benchmark
5. ctx (входной контекст)
6. out (max output)
7. R (reasoning: да/нет)
8. Provider (название)
9. Exact ID (копируемый)
10. Status (badge)
11. Kind (free/preview/paid badge)
12. Limit (RPM/RPD/Freebucks)
13. Note (короткая)

Всё в одной строке. На мобильном — карточки с теми же полями.

## Фильтры (все в одной панели над таблицей)
- Search (по модели, провайдеру, ID, задаче, benchmark)
- Provider pills
- Kind pills (Free/Preview/Paid)
- Status pills
- Task pills
- Context window pills (≥32K/≥128K/≥256K/≥1M)
- Reasoning pills (да/нет)
- Сортировка: по rank / по ctx / по provider / по status

## Дополнительно
- Счётчик: "N / M routes" + "X free · Y preview · Z paid · W blocked"
- Кнопка "Сбросить фильтры"
- Sticky header таблицы при скролле
- Подсветка provider цветом
- Hover: показать полный note
- Копирование ID в один клик (уже есть)

## Удаление дублей
- Убрать дублирование entries (например, DeepSeek V4.1 Flash показывается 7 раз — это правильно, но нужна группировка по семейству с раскрываемым списком провайдеров).
- Альтернатива: одна строка на (семейство × провайдер) — уже так и есть. Оставить, но добавить группировку по семейству с collapse.
