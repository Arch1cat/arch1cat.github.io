## Архитектура v11

### 1. Новые вкладки (7)
`01 Free AI` · `02 Рейтинг` · `03 Сравнитель` · `04 Free API` · `05 Инструменты` · `06 Тарифы` · `07 Новинки`

### 2. Сравнитель (главная новая фича)
- Мультивыбор моделей: чекбоксы в каталоге + пикер с поиском в самой вкладке.
- Итоговая таблица по выбранным (до 8): строки = параметры (ctx, out, reasoning), бенчмарки (SWE, HE, Aider, Arena), доступность (провайдеры, статус, exact ID с копированием), тариф/лимит (бесплатно или подписка), для кого.
- «Кто лучше» — авто-вердикт по взвешенному score (качество 45% / контекст 20% / доступность 20% / цена 15%) с пояснением.
- Кнопка «экспорт в Markdown» — копирует сводку.

### 3. Интерактивные графики (единая модель выбора)
- `state.sel` — массив выбранных famId (до 8). Клик по любой точке/бару/строке графика → toggle выбора.
- Выбранные подсвечены во **всех** графиках (ring + яркая обводка), остальные приглушены.
- Панель «Выбрано: N» с чипсами, кнопки «Сравнить» / «Очистить».
- Легенда кликабельна.

### 4. ctx × SWE переделан
- Цвет = кластер провайдера (9 цветов), размер = out-токены, обводка = статус (working/catalog).
- Сетка + подписи осей + легенда провайдеров (кликабельная → фильтр по провайдеру).
- Подписи лидеров, чтобы не «все на одном уровне».

### 5. Тарифы → «Варианты и трафик»
- Таблица вместо «витрины»: Цена | Квоты/трафик | ≈ токенов | Модели | Токенов на $ | Наш сервис? | Источник.
- Сортировка по цене/трафику/эффективности, фильтр «до $30/мес».
- Нормализация в единицу «млн токенов/мес» и «запросов/мес» — чтобы сравнивать разные модели провайдеров между собой.
- Отдельный блок «Наши варианты» (Nous, OpenCode Go, OmniRoute, CommandCode) — помечены, но НЕ единственные.

### 6. Free API — новая вкладка
Каталог 24 free-провайдеров: ключ нужен/не нужен · лимиты (RPM/RPD/токены) · карта нужна · тир моделей · сколько в месяц реально · для кого. Сортировка по трафику.

### 7. Рейтинг — понятная структура
Карточки топ-5 (score + составляющие) → полная таблица: провайдер · score · free-моделей · working · лимиты · тариф от · доступ у нас. OmniRoute в списке явно помечен как локальный шлюз.

### 8. Данные
`gen_free_ai_js.py`: расширить PLANS (поля: price, quota, tokensPerMonth, models, tools, ours, source, efficiency), добавить FREEPROV (24 записи), обновить PROVIDERS (OmniRoute уже есть — добавить в новый блок), ranking пересчитается.
