# arch1cat — «CYBER WORKSTATION & AUDIO DECK 3D» Theme Overhaul Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.
> **Context:** Пользователь недоволен абстрактным тором и простой сменой цветов ("пустой и слабый дизайн, абстрактные фигурки — это гавно"). Требуется **настоящая богатая 3D-тема с детальными анимированными 3D-объектами**, основанная на лучших GitHub WebGL-портфолио (3D рабочее место / 3D Hi-Fi стойка / 3D интерактивный деск).

**Goal:** Создать кардинально новую, богатую и высокоинтерактивную 3D-тему **«CYBER WORKSTATION 3D»** с 3D-рабочим столом разработчика, детальной 3D Hi-Fi кассетной/виниловой стойкой плеера, 3D механической клавиатурой, 3D кибер-котом и парящими 3D-экранами проектов. Все 3D-элементы строятся процедурно на Three.js r170 (без тяжелых/ненадёжных внешних GLTF-файлов) и реагируют на мышь и клавиатуру.

**Architecture:**
- Включается тумблером в хедере как глобальная тема `data-theme="workstation"` (рядом с `archive` и `deck`).
- В `assets/js/three-scene.js` вместо абстрактного тора строится полноценная **3D-сцена Cyber Workstation**:
  1. **3D Ultrawide Монитор / Терминал:** 3D-изогнутый монитор на стойке. На экране через `CanvasTexture` бежит живой матричный код / данные термнала.
  2. **3D Hi-Fi Аудио-стойка (Кассета + Винил):**
     - 3D-кассетная дека с вращающимися бобинами внутри прозрачного окна и нажимающимися 3D-кнопками (Play/Eject).
     - 3D-винил с вращающейся пластинкой, поворачивающимся тонармом и кольцом из 64 3D-спектр баров.
     - Клик по 3D-кассете или винилу напрямую в WebGL запускает/ставит на паузу генеративный звук и меняет треки!
  3. **3D Механическая Клавиатура:** Детальная 3D-клавиатура с отдельными кейкапами. Ховер подсвечивает клавиши и сдвигает их вниз. Нажатия клавиш на физической клавиатуре пользователя (`keydown`) заставляют 3D-кейкапы нажиматься и выпускать искорки (`Sparkles`)!
  4. **3D Кибер-Кот (Mascot):** Процедурный 3D-кот (голова, уши, моргающие глаза, виляющий хвост), сидит на мониторе, виляет хвостом, мурлычет при клике!
  5. **3D Парящие Голо-Экраны Проектов:** Вокруг рабочего места в 3D-пространстве парят 5 экранов с иконками проектов (World Monitor, WiFi Scanner, Metadata Cleaner, Cats Match-3, openGym). Клик по 3D-экрану переключает фокус на карточку проекта или открывает GitHub!

**Tech Stack:** Three.js r170 (ES module via importmap), Web Audio API (генеративный синтез), CanvasTexture, InstancedMesh, Raycaster, HTML5/CSS3 Tailwind, GitHub API (кэш 60м + fallback).

### Task 1: Подготовка темы `data-theme="workstation"` и токенов в CSS

**Objective:** Завести новый пресет `workstation` в CSS и логику переключателя в `index.html`/`ui.js`.

**Files:**
- Modify: `assets/css/style.css`, `assets/js/ui.js`, `index.html`

**Step 1:** В `assets/css/style.css` добавить блок `html[data-theme="workstation"]`:
```css
html[data-theme="workstation"] {
    --ink: #07090E;
    --surface: #0E1320;
    --plate: #0B101D;
    --bone: #E4EBFF;
    --muted: #6B7B9E;
    --ember: #00F0FF;     /* Неоново-циановый акцент */
    --ember-2: #FF2E93;   /* Неоново-розовый акцент */
    --ice: #00FF9D;       /* Изумрудный акцент */
    --line: rgba(0, 240, 255, 0.15);
}
```

**Step 2:** В `index.html` обновить тумблер тем в хедере (циклический выбор: `archive` → `deck` → `workstation` → `archive`).

**Step 3:** В `assets/js/ui.js` подправить `themeSwitch()` для поддержки 3 тем с всплывающими тоастами.

**Verify:** Клики по тумблеру переключают между 3 темами, токены меняются без ошибок в консоли.

### Task 2: Процедурная 3D-модель Рабочего Стола и Монитора в `three-scene.js`

**Objective:** Построить 3D-стол и 3D-изогнутый монитор с динамической текстурой экрана.

**Files:**
- Modify: `assets/js/three-scene.js`

**Step 1:** Создать группу `workstationGroup`:
- **Стол:** `BoxGeometry` стол с темной метало-деревянной текстурой (`MeshStandardMaterial`, roughness 0.3, metalness 0.7).
- **Подставка монитора:** Цилиндрическая хромированная ножка + плоская подставка.
- **Корпус монитора:** Изогнутая `BoxGeometry`/`ExtrudeGeometry` (ширина 4.8, высота 2.2, глубина 0.3).
- **Экран монитора:** `PlaneGeometry` с `CanvasTexture` (512x256 2D canvas).

**Step 2:** Создать процедурный генератор экрана (`updateMonitorScreen(time)`):
- Рисует на 2D-канвасе бегущий зеленый/циановый код терминала, логотип `ARCH1CAT // CYBER OS` и пульсирующий график активности.
- Флаг `screenTexture.needsUpdate = true` обновляет 3D-экран в рендер-лупе.

**Verify:** На сцене в теме `workstation` вместо тора виден 3D-монитор на столе с бегущим живым кодом на экране.

### Task 3: 3D Hi-Fi Кассетная Дека и 3D Винил (Интерактивный 3D-Плеер) ⭐

**Objective:** Построить детализированную 3D Hi-Fi стойку с вращающимся винилом, кассетой, тонармом и спектром.

**Files:**
- Modify: `assets/js/three-scene.js`

**Step 1:** Создать группу `audioDeckGroup` на 3D-столе справа от монитора:
- **3D Кассетная Дека:** Корпус кассетника z=0.5. Внутри прозрачного окна (`MeshPhysicalMaterial` стекло) вращаются 2 3D-бобины кассеты.
- **3D Кнопки кассетника:** 4 3D-кнопки (Play, Stop, Next, Prev), которые утопают при клике мышью в WebGL!
- **3D Виниловый проигрыватель:** 3D-диск с ярким оранжево-розовым яблоком, поворачивающийся металлический тонарм с иглой.
- **3D Спектральное кольцо:** 64 3D-столбика `InstancedMesh`, выстроенных полукругом вокруг винила, реагирующих на частоты `window.__deckAudio`.

**Step 2:** Интерактивность по Raycaster:
- Клик по 3D-винилу или 3D-кассете переключает `window.__deckAudio.toggle()`.
- При воспроизведении тонарм плавно опускается на диск, кассетные бобины вращаются, 3D-спектр анимируется!

**Verify:** Клик по 3D-проигрывателю на сцене запускает аудио, тонарм двигается, 3D-столбики спектра прыгают под музыку.

### Task 4: 3D Механическая Клавиатура и Интерактив Нажатий Клавиш ⭐

**Objective:** Построить 3D-клавиатуру на столе. Нажатия на физическую клавиатуру нажимают 3D-клавиши и выбивают искры.

**Files:**
- Modify: `assets/js/three-scene.js`, `assets/js/ui.js`

**Step 1:** Создать 3D-клавиатуру:
- Корпус `BoxGeometry` (ширина 2.4, глубина 0.9, высота 0.1).
- 60 отдельных кейкапов `BoxGeometry(0.1, 0.08, 0.1)` с цветовым разделением (основные клавиши светлые, Enter/Esc — неоново-розовые/циановые).

**Step 2:** Обработка реальных нажатий клавиш пользователя:
- В `assets/js/ui.js` на событие `keydown`: выбирается случайный 3D-кейкап клавиатуры (или маппинг по коду), кейкап утапливается вниз по Y на 0.04u и упруго возвращается назад.
- Из точки нажатой 3D-клавиши вылетает пучок ярких 3D-искр (`ParticleSystem` / `Sparkles`)!

**Verify:** Нажатие любой клавиши на клавиатуре ноутбука/ПК вызвает физический клик 3D-клавиши на экране и салют искр!

### Task 5: 3D Кибер-Кот Маскот (Petdex Mascot) ⭐

**Objective:** Добавить процедурного 3D-кота, сидящего на мониторе.

**Files:**
- Modify: `assets/js/three-scene.js`

**Step 1:** Построить 3D-модель кота на мониторе:
- Голова (скругленный куб), туловище, 2 ушка-пирамидки, светом светящиеся 3D-глаза, хвост из изогнутой `TubeGeometry`.

**Step 2:** Анимации кота:
- Хвост плавно виляет из стороны в сторону (`sin(time * 2)`).
- Глаза периодически моргают (прижатие шкалы Y у глаз на 100мс каждые 4 секунды).
- Клик по коту в WebGL вызываeт довольный поворот головы, вспышку глаз и звук мурлыканья/милого синт-бипа!

**Verify:** Кот сидит на 3D-мониторе, виляет хвостом, моргает и реагирует на клики.

## Risks / Tradeoffs

| Риск | Решение |
|---|---|
| Слишком много 3D-объектов вызовет падение FPS | Использование `InstancedMesh` для клавиш/спектра, процедурные простые геометрии вместо тяжелых сетчатых файлов GLTF |
| Звук не воспроизводится из-за правил автоплея | Звук запускается строго по первому пользовательскому клику по 3D-плееру или кнопке |
| 3D-текст плохо читается | Текстовый контент остается в резком HTML/CSS слое, а 3D-экраны служат интерактивным визуальным дополнением |
| Медленный скролл | Уважение к `prefers-reduced-motion` и оптимизированный `requestAnimationFrame` с авто-паузой при скрытой вкладке |
