# План разработки: 3D-печать под заказ (AURA 3D)

**Цель:** Создать высокотехнологичный, минималистичный и премиальный лендинг 3D-печати под заказ на стеке Vite + React + TypeScript + Tailwind CSS + React Three Fiber + drei + GSAP ScrollTrigger + Lenis, с центральной интерактивной 3D-моделью, скролл-анимациями, реакцией на скролл, поддержкой мобильных устройств и интеграцией в `arch1cat_site` отдельной ссылкой.

---

## 1. Стек технологий
- **Сборщик и среда:** Vite 5 + React 18 + TypeScript
- **Стилизация:** Tailwind CSS + кастомный дизайн-токен для неонового оранжевого накала сопла 3D-принтера (`#ff5500`, `#ff7700`)
- **3D Графика:** Three.js + `@react-three/fiber` + `@react-three/drei`
- **Анимации и скролл:** GSAP 3 (ScrollTrigger) + Lenis (гладкий скролл с интерполяцией)
- **Иконки:** Lucide React

## 3. Архитектура центральной 3D-модели
- **Концепция:** Параметрическая высокоточная деталь (комбинация аэрокосмической турбинной геометрии, гироидной внутренней структуры и полигональной сетки).
- **Легковесность:** Полностью процедурная геометрия на чистом Three.js (0 КБ внешних тяжелых gltf-файлов, мгновенная загрузка, 60-120 FPS).
- **Стейты по скроллу:**
  1. *Hero:* Парящая деталь под углом 45°, медленное вращение, оранжевый акцентный свет от сопла.
  2. *От идеи к модели (CAD):* Переход в режим топологической сетки (wireframe + vertex dots), отображение осей координат и расчетной сетки.
  3. *Печать слой за слоем:* Активный эффект среза (clipping plane / dynamic layer height), лазерная линия спекания и частицы расплавленного пластика.
  4. *Готовый объект:* Монолитный композитный материал (Carbon PEEK / матовый анодированный титан), вращение на 360°, реакция на курсор мыши.
  5. *Контакты:* Подъем модели, мягкое свечение в глубине, акцент на CTA.

## 4. Пошаговый план реализации
1. Инициализировать `package.json`, установить и настроить зависимости (React, Three, R3F, GSAP, Lenis, Tailwind).
2. Настроить `vite.config.ts` с `base: './'` и компиляцией в папку `../3d-print`.
3. Реализовать системные стили `index.css` и `tailwind.config.js` с темной палитрой и горячим оранжевым акцентом сопла.
4. Разработать процедурную 3D-модель `ModelScene.tsx` и шейдер/эффект слоев печати.
5. Интегрировать Lenis + GSAP ScrollTrigger в `App.tsx` и `scrollManager.ts`.
6. Реализовать все секции лендинга:
   - Header с телеметрией
   - Hero «AURA — 3D-печать под заказ / Идеи становятся объектами»
   - «От идеи к модели»
   - «Печать слой за слоем» с интерактивным прогрессом
   - «Готовый объект» с характеристиками материалов
   - Интерактивный калькулятор стоимости и веса
   - Секция контактов (Telegram, Instagram, Email)
   - Кнопка возврата в arch1cat.site
7. Собрать проект командой `npm run build` в `3d-print/`.
8. Добавить ссылку в `index.html` (в хедер и в список работ сайта arch1cat).
9. Проверить работу в браузере, протестировать адаптивность под мобильные экраны и скролл.
